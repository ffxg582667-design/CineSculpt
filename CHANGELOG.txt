CineSculpt 开发日志 / 代码日志
========================================

项目：电影场景 3D 打印 AI Agent（MakerMuse 黑客松）
定位：上传电影截图 -> AI 重建 3D 模型 -> 微调 -> 导出 STL 打印

========================================
一、技术架构
========================================
前端：HTML + Three.js（ES module + importmap），3D 预览/旋转/缩放
后端：Python + Flask（threaded=True）
3D 重建：Tripo3D API（官方 SDK）
  - 图生 3D：image_to_model（上传图片时）
  - 文生 3D：text_to_model（填写出处时）
文字理解：DeepSeek API（把“出处”扩写成 3D 提示词）
抠图：rembg（alpha matting + 白底合成）
网格处理：Trimesh + fast_simplification（修复/简化/体素重建/导出 STL）
公网：Cloudflare Tunnel

========================================
二、文件结构
========================================
backend/app.py          主服务，所有 API 路由
backend/reconstruct.py  3D 重建（图生/文生 + 占位 fallback）
backend/describe.py     DeepSeek 提示词生成
backend/segment.py      rembg 抠图
backend/mesh_ops.py     网格操作（修复/加底座/缩放/简化/打印性检测/导出）
frontend/index.html     页面结构
frontend/style.css      样式（Space Grotesk 字体）
frontend/app.js         Three.js 预览 + 交互逻辑
start.bat               一键启动（含密钥，不入版本控制）
stop.bat                一键停止

========================================
三、开发历程（关键里程碑）
========================================
1. 搭建完整 Web 链路：上传 -> 重建 -> 3D 预览 -> 微调 -> 导出 STL
2. 修复中文乱码（问号）：所有中文改用 \u 转义写入，避开 PowerShell 编码破坏
3. 统一字体：Space Grotesk（科技感）
4. 依次添加/删除图片功能
5. 接入真实 3D 重建：先试 Meshy（免费额度不可用）-> 改用 Tripo3D（免费额度可用）
6. 修复微调 404：重建/微调/导出改为基于磁盘文件，前端锁定已重建的 session
7. 修复多图重建失败：multiview 参数严格，改为统一用单图重建
8. 微调改造：拆成“AI 一键修理” + “人工微调”两步
9. 加强 AI 修理：去碎片 + 补洞 + 体素重网格化（强制水密可打印）
10. 修复 AI 修理卡死：预简化 + 体素分辨率 128->64 + 尺寸归一化 + 多线程（从卡死降到 12 秒）
11. 接入路线 B：DeepSeek 把“出处”扩写成提示词 -> Tripo 文生 3D

========================================
四、已知限制
========================================
- 3D 模型精细度取决于 Tripo 免费版（默认 v2.5），升级版本/开纹理会额外消耗积分
- 文生 3D 不看图，生成的是符合文字描述的模型，未必完全像原图
- 重建需 1-2 分钟（云端 AI 计算，无法加速）
- session 存内存，重建后模型存磁盘（服务重启不丢）
